# 记账本 · Expense Tracker

一个手机优先的个人记账小应用。记录每一笔支出，看清钱花在哪里。

## 功能

- **记一笔**：金额 + 分类 + 备注（可选）+ 日期
- **本月总览**：本月总支出、今日支出、笔数
- **分类占比**：本月各分类的花费与占比，按金额排序
- **明细列表**：按日期分组，显示当日小计
- **删除可撤销**：删错了点「撤销」就能救回来
- **月份切换**：可以回看历史月份

## 技术说明

纯静态页面，零依赖、零构建步骤：

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 样式（移动优先，最大宽度 520px） |
| `app.js` | 全部逻辑（约 400 行，无框架） |

数据保存在浏览器的 `localStorage`（键名 `expense_records_v1`），不上传服务器，不需要注册登录。

## 本地运行

直接双击 `index.html` 即可。或者用任意静态服务器：

```bash
python -m http.server 8099
```

然后打开 <http://127.0.0.1:8099>。

## 数据说明

- 数据只存在你自己的浏览器里，换设备或清理浏览器数据会丢失。
- 想换手机也能看到，需要加账号登录 + 云端存储。
